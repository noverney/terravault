# TerraVault examples

Examples are grouped by workflow so acquisition, local queries and derived
postprocessing do not become mixed together.

| Folder | Purpose |
|---|---|
| `switzerland_patch/` | STAC, Process API and public-thumbnail retrieval examples |
| `query/` | Read and stitch an already downloaded DuckDB/COG dataset locally |
| `postprocessing/` | Turn TerraVault query products into downstream analysis formats |

All commands are intended to be run from the repository root after
`python -m pip install -e .`.
