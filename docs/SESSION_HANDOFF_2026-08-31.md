# Session handoff — three-source Swiss monthly vegetation composites

Date: 2026-08-31. Scope for this phase: **July 2024 only**, one test month across three
sources. Goal: a high-resolution monthly orthomosaic per source plus the four
vegetation indices, and a comparison report with coverage, distribution and timing.

## The three sources (provenance is explicit and separate)

1. **swissEO S2-SR** (`swisseo-monthly`) — published swisstopo orbit mosaics, public
   STAC, no token. Bands read from per-item metadata, not assumed order.
2. **Direct Copernicus L2A** (`copernicus-monthly`) — CDSE L2A bands
   (B03/B04/B05/B08/B8A/B11) + SCL/CLD masks, per-pixel masked monthly median.
3. **Post-FORCE** (`monthly`) — monthly median from genuine FORCE BOA/QAI pairs.

Vegetation indices (source-neutral, TreeAI used only as the formula reference):
NDVI, GNDVI, NDRE, NDWI — definitions in [`terravault/vegetation.py`](../terravault/vegetation.py).

## Important operational notes

- Both `/Volumes/upscale` (SMB) and `/Volumes/T7` (exFAT) drop when the machine
  sleeps or the network changes. Verify `mount | grep -E 'upscale|T7'` before runs.
- exFAT T7 periodically loses write permission for the terminal app (macOS TCC
  removable-volume grant). If writes fail, re-grant Full Disk Access / Removable
  Volumes to the terminal app and re-plug the drive.
- Never write an in-progress GeoTIFF directly to the SMB share (random-seek writes
  fail / drop). Compute locally on the T7, then copy finished files to the share.
